# Тесты системы голосования Poranam

Этот каталог содержит тесты для проверки функциональности системы голосования после исправления багов.

## Запуск тестов

### Логические тесты (рекомендуется)
Логические тесты проверяют корректность алгоритмов без подключения к базе данных:

```bash
php tests/logic_tests.php
```

### Полные тесты (требуют настроенной БД)
Полные тесты проверяют работу с реальной базой данных:

```bash
php tests/run_all_tests.php
```

## Что тестируется

### 1. Логика "Выбрать всех участников"
- Проверка, что при выборе опции "Выбрать всех участников" все поля критериев сохраняются как пустые строки
- Проверка, что при обычном выборе поля сохраняются с введенными значениями

### 2. Проверка прав на голосование
- Голосования "для всех" (все критерии пустые) - любой пользователь может голосовать
- Голосования с критериями - только пользователи, соответствующие критериям, могут голосовать
- Проверка соответствия по субъекту, региону, профессии, городу, индексу, улице, дому, рангу

### 3. Логика фильтрации голосований
- Пользователь видит голосования, где он участвует ИЛИ участвуют все
- Правильное построение SQL условий с логикой ИЛИ для пустых полей

### 4. Логика расчетов
- Корректный расчет процента проголосовавших
- Обработка деления на ноль

## Исправленные баги

Тесты проверяют исправления следующих багов:

1. **Некорректный расчет участников** - исправлено сопоставление полей в `el_calcVoteUsers()`
2. **Отсутствие проверки прав на голосование** - добавлена валидация в `init_vote.php`
3. **Неправильная фильтрация голосований** - исправлена логика в `el_buildCatalogSubQuery()`
4. **Проблемы с UI полей** - исправлены в JavaScript обработчиках
5. **Неполная реализация "Выбрать всех участников"** - добавлена логика сохранения пустых полей

## Структура файлов

- `logic_tests.php` - логические тесты без БД
- `voting_tests.php` - функциональные тесты с БД (требуют настройки)
- `run_all_tests.php` - полный набор тестов включая синтаксическую проверку
